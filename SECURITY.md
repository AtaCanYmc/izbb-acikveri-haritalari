# Security Policy

## Supported Versions

Only the latest release deployed on the `main` branch receives active security patches.

| Version | Supported | Notes |
| --- | --- | --- |
| `main` (Latest) | Yes | Actively maintained with security and dependency updates |
| `< 1.0.0` | No | Legacy preview tags. Upgrade to the latest commit on `main` |

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not disclose it publicly in an open issue or discussion forum.

### Reporting Procedure

1. Submit a private vulnerability advisory through GitHub:
   [Report a Vulnerability](https://github.com/AtaCanYmc/izbb-acikveri-haritalari/security/advisories/new)
2. If GitHub Security Advisories is unavailable, contact the project maintainer directly via GitHub profile: [@AtaCanYmc](https://github.com/AtaCanYmc).

### Required Details

Please provide the following information in your advisory:
- Description of the vulnerability and its potential impact.
- Exact reproduction steps or proof-of-concept code.
- Specific files, dependencies, or endpoints affected.
- Suggested remediation or workaround if known.

### Response SLA

- **Initial Response:** Within 48 hours of report receipt.
- **Triage & Status Update:** Within 5 business days with an assessment and estimated remediation timeline.
- **Public Disclosure:** Coordinated only after a patched release is published and deployed.
